# 学习中心（docker 版）

小学中高年级的互动学习网站：浏览器打开就能用，电脑鼠标和平板触屏都能操作。

- **首页**：按**年级**（1~6 年级）和**专题**（数与代数 / 图形与几何 / 统计与概率 / 应用与思维）筛选，支持关键词搜索（工具名、知识点、别名都能搜到），学过的工具显示星星
- **数学 109 个**（首页分「🧰 工具」和「✏️ 练习题」两类）（**苏教版四年级**重点：首页默认显示四年级，可按「苏教版四上 / 四下」筛选，卡片上标有对应单元）：
  - **32 个练习题**（通用练习引擎；纯计算类、纸笔就能做的题不收录）：每个都有「知识点讲解」→ 分难度 → 10 题（数字键盘 / 选择题，电脑键盘也能输入）→ 错题解析 → 星星；涵盖数位与大数、估算、分数意义、单位换算、百分数、比和比例、应用题（行程/鸡兔同笼/工程）、周长面积体积、圆与圆柱圆锥、角、统计与可能性等
  - **77 个互动工具**：钟表、数轴、九九乘法表、计数器、24 点、分数可视化、百分比涂格子、3D 长方体、量角器、面积周长、轴对称、三角形内角和、圆的探索、平行四边形变长方形、转盘与可能性、条形统计图（可调每格代表数）、三阶魔方、搭小正方体、长方体和正方体展开图、割圆术、小狗活动区域、草地铺路、时间线段图、心跳计时器、锯木头、无限对半切、认识长方体、体积单位、圆柱切拼、卷圆柱、绳子对折、画三角形的高、三角形梯形面积推导、拼长方体、公因数公倍数集合图、分数加法、钟表练习、十格图凑十法、楼梯铺地毯、公式大全与计算器（长方形面积=长×宽等 30 个公式，改数字就能算）、垂直线段最短、周长展开、运算律点子图、移多补少求平均数、三角形三边关系、数位顺序表、小数的意义与小数点移动、垂直与平行、竖式除法试商、平行四边形和梯形、鸡兔同笼列表法、方格里的周长与面积、数量关系、点一点算混合运算、旅游计划、数字卡片组数、一亿有多大、数轴近似数、变换操作台、三位数乘两位数面积图、计算器探索规律、运算律实验室、多边形内角和、三角形分类、数对、身份证里的秘密、观察物体（搭积木看三视图）、平移旋转轴对称、汉诺塔、年历、数独等（拖拽用指针事件，鼠标和手指通用）

服务端只用 Node 自带模块，构建时不需要 npm install。

## 部署

新建一个目录，放入 `docker-compose.yml`（或贴到 1Panel 的编排里）：

```yaml
services:
  study-hub:
    image: ghcr.io/lu8010252/study-hub:latest
    container_name: study-hub
    restart: unless-stopped
    ports:
      - "8040:8040"
    environment:
      - TZ=Asia/Shanghai
      - ADMIN_PIN=      # 家长密码，留空=不设；设置后英语模块清除/删除/导入需要输入
    volumes:
      - ./data:/data
```

`docker compose up -d`，访问 `http://服务器IP:8040`。更新：`docker compose pull && docker compose up -d`。
镜像由 GitHub Actions 在每次推送 main 后自动构建（amd64 / arm64）。

## 加一个新工具

工具清单的源头是 `tools/registry.js`，改完运行 `node tools/build.js` 会生成 `public/tools.json`（首页用）和各练习题型页面。

- 教材对应关系按课本目录页写在 `registry.js` 的 `units`（单元顺序）和 `tb`（id → [册, 单元]）里；选了「苏教版四上/四下」后按单元顺序排列。
- **加一个练习题型**：在 `public/js/qd-*.js` 里加 `Quiz.defs['id'] = { title, intro(知识点html), levels, gen(level) }`（gen 返回 `{q, a, exp, ...}`，写法见 `public/js/quiz.js` 顶部注释），再在 `registry.js` 里加一行（类型 `quiz`）。
- **加一个互动演示**：新建 `public/math/<id>/index.html`，引入 `/css/hub.css` 和 `/js/tool.js`，用 `Hub.bar('标题')` 生成顶栏，答对后 `Hub.star('<id>', 1~3)` 记星星；在 `registry.js` 里加一行（类型 `page`）。

触控提示：拖拽用 pointer 事件（鼠标和手指通用），按钮高度不小于 44px。
